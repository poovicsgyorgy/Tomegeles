# Tömegelés 💪

Telefonra telepíthető webapp Bálint tömegeléséhez.

- **Ma:** napi terv (mai edzésnap, kalória-, fehérje- és vízcél, teendők, visszajelzés a tegnapról, napi tipp)
- **Kaja:** gyors hozzáadás magyar alapételekből, saját ételek, makrók, ötlet a hiányzó kalóriára
- **Edzés:** Push/Pull/Láb sablonok, szettnapló, „múltkor” értékek, +2,5 kg javaslat, PR jelzés, pihenőidő-stopper
- **Fejlődés:** testsúly-grafikon 7 napos átlaggal, heti tempó, célig hátralévő idő, erő (becsült 1RM), körméretek
- **Napi fotó:** a fotók csak a telefonon tárolódnak, összehasonlítás a kezdéssel
- **Heti összefoglaló:** súlyváltozás, átlagkalória, fehérje, edzések, PR-ok és tanács a következő hétre
- **Heti étrend:** 6 étkezés naponta a kalóriacélhoz méretezve, csere gomb, „Megettem” egy koppintással, bevásárlólista
- **Tudás:** kutatásokon alapuló irányelvek forrásokkal
- Okos kalóriaigazítás: 2 hét mérés után ±150 kcal javaslat a valós súlyváltozás alapján

Az adatok a telefonon tárolódnak (localStorage). Mentés: ⚙️ → Mentés fájlba.
